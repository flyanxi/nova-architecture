# NOVA — Архитектурное бюро

Современный, адаптивный и доступный прототип лендинга для архитектурного или дизайнерского бюро. Проект построен по принципу Mobile First с использованием кастомизированного CSS, делает упор на дизайн-токены, современную сетку и премиальные визуальные эффекты.

## Особенности проекта

* **Премиальный UI/UX:** Строгая типографика и тщательно подобранные цвета.
* **Глассморфизм:** Фиксированная шапка сайта с эффектом матового стекла.
* **Интерактивная сетка:** Смещенная журнальная раскладка для портфолио с эффектами при наведении.
* **Доступность (A11y) и SEO:** Использование семантических тегов, атрибутов `aria-label` и поддержка управления с клавиатуры.
* **Модульный подход:** Разделение JavaScript на логические модули, а CSS — на базовые стили, компоненты и лейауты.

## Технологии

* **HTML5:** Семантическая разметка и доступность.
* **CSS3:** Flexbox, CSS Grid, кастомные анимации.
* **JavaScript (ES6+):** Модульная архитектура для обработки навигации, анимаций и плавного скролла.

## Структура файлов

* `index.html` — Главный HTML-документ.
* `src/` — Исходные файлы проекта:
  * `assets/` — Статика: локальные шрифты (`fonts/`) и оптимизированные изображения/вектор (`images/`).
  * `scripts/` — Логика: основной скрипт (`main.js`) и отдельные функции в `modules/` (`animations.js`, `navigation.js`, `smoothScroll.js`).
  * `styles/` — Стили проекта, разбитые по логике (`base.css`, `components.css`, `layouts.css`).
* `package.json` / `package-lock.json` — Зависимости и скрипты сборки проекта.
* `.gitignore` — Исключения для системы контроля версий.

## Как запустить

1. Скачайте или клонируйте этот репозиторий на свой компьютер.
2. Установите зависимости, выполнив команду `npm install`.
3. Запустите локальный сервер для разработки с помощью команды `npm run dev` (или скрипта, указанного в вашем package.json).
4. Соберите оптимизированный проект для деплоя командой `npm run build`.
